EASY CONTENT CHANGES
--------------------
Open: site-config.js

That file contains your platform links, release details, artwork path, support links, social links and the PUBLIC Turnstile site key.

Do NOT put these secrets in GitHub or site-config.js:
- RESEND_API_KEY
- TURNSTILE_SECRET_KEY

Those stay in Cloudflare > Workers & Pages > v3breaks > Settings > Variables and Secrets.

CLOUDFLARE VARIABLES
--------------------
Keep these configured for Production:
- RESEND_API_KEY = encrypted Secret
- CONTACT_TO_EMAIL = your private inbox
- CONTACT_FROM_EMAIL = your Resend sender
- TURNSTILE_SECRET_KEY = encrypted Secret

CUSTOM DOMAIN
-------------
Attach v3breaks.com to the EXISTING Cloudflare Pages project. Do not create a new project.

TURNSTILE
---------
Your Turnstile widget should allow:
- v3breaks.com
- v3breaks.pages.dev temporarily while testing

RESEND
------
Once v3breaks.com is verified in Resend, you can use a sender such as:
  v3 breaks <website@v3breaks.com>

CONTACT_TO_EMAIL can still be your private Gmail inbox.

DEPLOYING CHANGES
-----------------
Commit/upload changed files to the main branch of your GitHub repo. Cloudflare Pages will redeploy automatically.
